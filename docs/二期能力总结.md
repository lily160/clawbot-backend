> 状态：本阶段聚焦「提醒 / OTC / 体检模板 / 日常健康记录」四大块，全部可演示、可验收。
> 依据：[项目脉络.md](./ClawBot健康管家-项目脉络.md) §5.3「可后置（P2）」与 §11「一期验收标准」。
> 提交日期：2026-08-04。

---

## 1. 概述

二期在「建档 → 导诊 → 挂号」主流程之外，补齐了健康管理的**日常化闭环**：

- 主动触达：定时提醒（用药 / 喝水 / 运动 / 早睡 / 复查 / 自定义），到点由调度引擎推送；
- 事前预防：OTC 配伍冲突检测，录药即查、即警示；
- 个性化建议：体检套餐模板按年龄 / 性别 / 慢病 / 生活方式 / 孕期动态生成；
- 行为记录：喝水 / 运动 / 早睡打卡，同日同类累加。

一句话：**一期回答「病了去哪个科」，二期回答「平时怎么管好自己」。**

## 4. 二期明确不做（边界）

以下属于 P2 可后置、**本期验收排除**：

- 病历 / 检验「复诊一页纸」深度整理；
- 真医院 / 市平台适配器实装（一期接口已抽象，仅沙箱演示）；
- 完整药品说明书库、跨设备 Sync、本地大模型、硬件手环接入。

## 5. 演示与验证方式

- 一键演示脚本：`run-health-sim.cmd`（复用真实 Spring 上下文，逐条打印「用户输入 → 机器人回复」，含负例校验）。
- 单测覆盖：提醒 / 用药 / 打卡 / 体检模板均有 JUnit 5 用例（`mvn -pl bot test`，H2 内存库）。
- 运行前提：本地 MySQL（`127.0.0.1:3306/cloudbot`）已启动；演示脚本会先清理 `sim_health_user` 旧提醒与用药，保证每次跑是干净状态。
